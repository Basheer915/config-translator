# Транслятор конфигурационного языка (Вариант №1)

Инструмент командной строки на языке **Go** (с использованием библиотеки **`participle/v2`**) для преобразования учебного конфигурационного языка из стандартного ввода (`stdin`) в формат JSON.

## 1. Общее описание

Программа считывает конфигурацию из `stdin`, проверяет синтаксис, вычисляет константные выражения и сохраняет результат в выходной JSON-файл. При синтаксических или семантических ошибках сообщение выводится в `stderr`.

Поддерживаемые конструкции:
* **Комментарии:** `-- текст комментария`
* **Числа:** `\d+\.\d*` (например, `3.14`, `8080.0`)
* **Строки:** `q(текст)`
* **Массивы:** `[ значение значение ... ]`
* **Константы:** `var имя = значение`
* **Выражения:** `#{выражение}`

## 2. Функции и настройки

* **Ключ командной строки:** `-o <путь>` — путь к выходному JSON-файлу (по умолчанию `result.json`).
* **Операции:** `+` (сложение), `-` (вычитание).
* **Функции:** `max(a, b)` (максимум из двух чисел), `concat(s1, s2)` (склеивание двух строк).

## 3. Сборка и запуск тестов

Автоматический запуск тестов и сборки (Windows):
```bat
run.bat
```

Ручные команды:
```bash
# Запуск тестов
go test -v ./tests/...

# Сборка проекта
go build -o config_translator.exe ./src
```

Запуск транслятора:
```powershell
Get-Content examples\ci_pipeline.cfg | .\config_translator.exe -o output.json
```

## 4. Примеры использования

В папке `examples/` находятся 3 примера конфигураций из разных предметных областей:
1. `examples/ci_pipeline.cfg` — конфигурация CI/CD конвейера.
2. `examples/math_constants.cfg` — математические константы и вычисления.
3. `examples/web_server.cfg` — настройки веб-сервера.

**Пример входа (`examples/ci_pipeline.cfg`):**
```text
var env = q(production)
var retries = 3.0
var safe_retries = #{max(retries, 5.0)}
var stages = [ q(build) q(test) q(deploy) ]
```

**Результат (`output.json`):**
```json
{
  "env": "production",
  "retries": 3,
  "safe_retries": 5,
  "stages": ["build", "test", "deploy"]
}
```
