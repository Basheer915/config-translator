================================================================================
ConfigTranslator — Инструкция по сборке, тестированию и запуску (Вариант №1)
================================================================================

1. ОПИСАНИЕ ПРОГРАММЫ
Инструмент командной строки для трансляции учебного конфигурационного языка
(Вариант №1) в формат JSON. Входные данные считываются из стандартного ввода
(stdin), результат записывается в JSON-файл, указанный через флаг -o.

--------------------------------------------------------------------------------
2. СБОРКА И ЗАПУСК ТЕСТОВ
--------------------------------------------------------------------------------
Автоматический запуск тестов и сборка (Windows):
  .\run.bat

Ручной запуск модульных тестов:
  go test -v ./tests/...

Ручная сборка исполняемого файла:
  Windows:
    go build -o config_translator.exe ./src
  Linux / macOS:
    go build -o config_translator ./src

--------------------------------------------------------------------------------
3. ЗАПУСК ПРОГРАММЫ (ПРИМЕРЫ КОМАНД)
--------------------------------------------------------------------------------
Синтаксис запуска:
  <ввод_конфигурации> | config_translator -o <путь_к_выходному_файлу.json>

Параметры командной строки:
  -o <путь>   Путь к выходному JSON-файлу (по умолчанию: result.json)

Примеры запуска в Windows (PowerShell):
  Get-Content examples\ci_pipeline.cfg | .\config_translator.exe -o ci_pipeline.json
  Get-Content examples\math_constants.cfg | .\config_translator.exe -o math_constants.json
  Get-Content examples\web_server.cfg | .\config_translator.exe -o web_server.json

Примеры запуска в Windows (CMD):
  type examples\ci_pipeline.cfg | config_translator.exe -o ci_pipeline.json

Запуск без предварительной сборки (через go run):
  Get-Content examples\ci_pipeline.cfg | go run ./src -o result.json
